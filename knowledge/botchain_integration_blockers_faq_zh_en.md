## BO Wallet signature attestation / BO Wallet 签名证明

【相关问题】BO Wallet 是否有钱包专属 attestation，能让后端证明签名来自 BO Wallet 而不是其他 EVM 钱包？isBoWallet 是否足够？ / Is there any wallet-specific attestation that proves a signature came from BO Wallet and not another EVM wallet? Can isBoWallet be spoofed?
【关键词】BO Wallet;attestation;isBoWallet;signature;backend verification;签名验证;钱包证明
【参考回答-中文】
目前没有有效机制可以验证某笔签名一定由 BO Wallet 生成，而不是其他 EVM 钱包。`isBoWallet` 可被伪造，不足以作为后端验签依据。
【参考回答-英文】
At the moment, there is no effective mechanism to verify that a signature was generated by BO Wallet specifically, instead of another EVM wallet. `isBoWallet` can be spoofed, so it is not enough for backend verification.
【来源】BOT Chain Integration Support | 2026-08-09

This conflict does not impact functionality. When adding the network to the wallet, please manually update the network name and native token name.

## dex-routing rate limit / quote TTL / SLA / dex-routing 限流与报价有效期

【相关问题】dex-routing 的 rate limit、quote 有效期、SLA、API 版本与废弃策略是什么？ / What are the rate limits, quote validity period, SLA and API versioning/deprecation policy for dex-routing endpoints?
【关键词】dex-routing;rate limit;quote;SLA;API versioning;30 seconds;30 minutes;报价有效期
【参考回答-中文】
会应用统一限流。展示与使用 quote 的建议有效期为 30 秒；链上 calldata 实际在 30 分钟后过期。更细的 SLA / API 版本与废弃策略以官方后续公布为准。
【参考回答-英文】
A unified rate limit will be applied. The recommended validity period for displaying and using quotes is 30 seconds, while the actual on-chain calldata expires after 30 minutes. Detailed SLA and API versioning/deprecation policy will follow official publications.
【来源】BOT Chain Integration Support | 2026-08-09
